1. 먼저 지켜야 할 네 가지

  1. 현재 파일과 에셋 ID는 임의로 변경하지 않습니다. 이 문서는 이미 연결된 이름을 설명하는 지침입니다.
  2. 배치는 이름이 아니라 ID로 연결합니다. objects[].assetId → assets[].id를 확인하고, 해당 레코드의 실제 파일 경로와 해시를 확인합니다.
  3. 배경 코드와 조명 코드를 함께 맞춥니다. 꽃·풀·돌은 같은 BGxx / LTxx를 기본으로 사용합니다. 공통 소스는 명시된 공통 사용 범위로 구분합니다.
  4. 이름이 비슷하다는 이유로 다른 그림을 대체하지 않습니다. 버전 숫자만 큰 파일도 자동 대체 대상으로 삼지 않습니다. 공식 매핑과 실제 원본을 확인합니다.

범위: 현재 공식 소스 87종 + 꽃잎 보조 소스 48종 = 목록 135종, 원본 PNG 183장입니다. 꽃 48종은 각각 봉오리·만개 두 장입니다. 별도로 이전 배치 복구용 v43 꽃 8종을 부록에 구분했습니다. 구름·새는 현재 공식 활성 목록에 없으므로 임의의 이름을 추가하지 않았습니다. 개인 브라우저에만 수동으로 추가한 소스는 이 공식 목록의 대상이 아닙니다.

7. 버전·교체·누락 처리 원칙

  1. 먼저 해당 배치의 assetId로 원본 에셋 레코드를 찾습니다.
  2. 현재 공식 매핑에 연결된 src와 PNG 원본의 SHA256을 확인합니다. thumb / preview는 원본 식별자로 사용하지 않습니다.
  3. 기존 파일이 없으면 같은 제작 계열·조명·종류·형태·상태의 공식 버전 매핑이 있는지 확인합니다. legacyAssetIds 등 명시된 호환 정보도 함께 확인합니다.
  4. 버전만 다른 같은 파일인지 확인된 경우에만 연결을 갱신합니다. v43 → v101처럼 제작 계열이 다르면 숫자가 크다는 이유만으로 교체하지 않습니다.
  5. 파일 이름이 같아도 해시가 다르면 덮어쓰지 않고 충돌로 기록합니다. 이름이 비슷한 다른 꽃으로 자동 대체하지 않습니다.
  6. 해결되지 않은 참조는 배경·에셋 ID·기대 파일명·배치 수를 누락 목록에 남깁니다.

BG01-B04-V05의 V05, 파일의 v101, 고정 ID의 v83, 매트 수정판 101-r4, 페이지 주소의 ?v=20261028-v95는 서로 다른 버전입니다. 같은 숫자 체계로 정렬하지 않습니다. 특히 페이지 URL의 v95를 보고 모든 리소스가 v95라고 판단하지 않습니다.

향후 새 제작판도 기존 제작 계열의 접두사·BG/LT·종류·형태·상태 토큰을 유지하고 제작 버전을 갱신합니다. 파일을 실제로 개명할 때는 에셋 레코드·카탈로그·시퀀스 매니페스트·내보낸 배치 JSON·다운로드 목록을 한 번에 검토해야 합니다. 이 지침서 작성 과정에서는 어떤 소스 파일도 개명하지 않았습니다.
