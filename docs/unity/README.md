# 제주 메이즈랜드 유화 전시 소재 v14 — 2026-10-20

네 가지 조명: 노을/레드, 낮/옐로우, 밤/퍼플, 아침/블루.
동백꽃·메밀꽃 / 금잔화·유채꽃 / 라벤더·수국 / 파랑 수국.
PNG 알파 96개: 만개 꽃 16, 봉오리 16, 잎·긴 잎줄기·풀 24, 현무암 16, 구름·나비·새 24.
배경과 통합 시안은 4.0704:1(14165×3480)이며, 실제 PNG 요소로 조립한 동일 배치입니다.
배경에는 꽃을 넣지 않았으므로 Unity에서 꽃이 이중으로 보이지 않습니다.
꽃은 전경 두 줄, 모든 요소 Z=0. 원근감은 배경에만 있습니다.

## Unity 사용
해당 시간대 ZIP 하나를 프로젝트 Assets 안의 전용 폴더에 풀고
Tools > Jeju > Import Layout JSON에서 그 ZIP의 layout.json을 선택합니다.
기본 임포트 결과는 만개 상태입니다. 같은 폴더의 budImage/openImage는 독립 PNG 상태입니다.
향후 터치 제어 구현 시 꽃에만 Collider/터치 영역을 적용하고 잎·풀·돌에는 적용하지 않습니다.
꽃 전체 PNG의 visibleBounds를 사용할 수 있으며 transparent padding은 16px입니다.
추가 조명 없이 Unlit 계열 Sprite 머티리얼을 사용합니다. 색감과 명암은 PNG RGB에 이미 적용했습니다.
동일 시간대끼리 조합하세요. 다른 시간대의 잎·돌을 섞으면 빛 방향이 달라집니다.
알파는 Straight RGBA, 투명 가장자리 확인 완료. 압축/필터링은 실제 벽면에서 조정해야 합니다.
원본 요소는 약 300~750px 범위이며 배경 생성 원본은 약 2K입니다.
14165×3480 파일은 비율을 맞춘 크롭 및 확대 출력이며 네이티브 14K 세부 묘사가 아닙니다.
개화 영상·중간 프레임은 포함하지 않습니다. 웹 전시는 두 PNG 상태 확인용입니다.
Unity 실행 및 실제 터치 장비 검증은 수행하지 않았습니다.

## 파일
*_editor_project.json: 웹 에디터 배치. *_unity_layout.json: Unity 좌표/레이어/상태 이미지 정보.
*_background_14165x3480.png: 벽면 크기 배경. *_integrated_14165x3480.png: 통합 비교 시안.
*_4096.png: 웹/빠른 비교용. asset_manifest.json: 크기·알파·원본·해시·크롭 기록.
생성지시문과원본기록.json: 이미지 생성 지시 및 사용한 참조 기록.
